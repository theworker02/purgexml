Overview

Purge and reshape xml text streams with deterministic transforms. Built as a tiny zero-dependency Node toolkit with a library API and a stdin-friendly CLI.

Usage

git clone https://github.com/theworker02/purgexml.git
cd purgexml
node src/cli.js --help
node --test
